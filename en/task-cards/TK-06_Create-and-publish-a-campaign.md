# 🎯 Task card TK-06 — Create & publish a campaign

> **For game managers.** How to set up a new campaign (learning journey) yourself in the Control Panel — no technical knowledge needed.
> **Status:** v1.0 · 30-08-2026 · part of the LearnStrike Knowledge Base · language: EN.

---

**A campaign is the "book"; challenges are its chapters.** Here you decide who gets to play, what it looks like and when it goes live. You add challenges and modules afterwards (TK-07, TK-09 through TK-12).

---

## 📌 Highlights

| | |
|---|---|
| **Where** | Control Panel → **Campaigns** → **New campaign** button |
| **When to use** | Every new learning journey; also the basis for a tournament (TK-14) or leagues (TK-15) |
| **What you need** | Name + short description (per language), campaign image (required), an icon if you want one |
| **Publication status** | Draft → Scheduled → Published (players only see it once it is published) |
| **Languages** | Multilingual organisation? Fill in the name and description **for every language** |
| **Permissions** | Manager role (or higher), 2FA active |

💡 **Looking for an action on a campaign and can't find it?** Open the campaign and check under the **three dots** to the right of the title. That is where duplicating, copying, achievements and If This Then That live, among others.

---

## 🚀 Step by step

1. Log in and open the **Control Panel** (menu, top right).
2. Click **New campaign** (or: **Campaigns** menu → **Add campaign**).
3. Fill in the basics:
   - **Name** and **Description** — for each available language (tabs above the field).
   - **Image** (required) and optionally an **Icon** — select or upload (PNG/JPG, max 10 MB).
4. Choose the **Access**:
   - **Everyone** — all logged-in users plus guests.
   - **Anonymous users** — guest users only.
   - **Registered users** — logged-in users only; optionally limited to certain **tags** (tick "Only users with a tag" and pick the tags). This is how you aim a campaign at one target group.
5. Set the display options (tick whatever you need):
   - **Challenges must be played in order** — a player can only start chapter 2 after chapter 1.
   - **Show points** / **Show stars** — what the player sees of their score.
   - **Hide leaderboard** — no leaderboard for this campaign.
   - **Awards certificate** — the player gets a PDF certificate on completion (for the layout, see TK-22).
6. Leave **Tournament mode** and **Leagues** switched off for now — they have their own task cards (TK-14, TK-15).
7. Handy: tick **Add dashboard tile** so the campaign appears on the player dashboard straight away (otherwise: TK-21).
8. Click **Save**. The campaign is now in your list as a **Draft**.
9. Add challenges and modules (TK-07 onwards).
10. Ready to go live? Open the campaign → **Edit** → tick **Published** and pick a **Published on** date and time. A future date gives the campaign the status **Scheduled**; it then goes live automatically.

---

## ⭐ Golden rules & common mistakes

- **Only publish once the content is there.** Players see a published campaign immediately — even if it only holds half a challenge.
- **Access via tags?** Check that your target group already **has** those tags (TK-05), otherwise nobody sees the campaign.
- **Multilingual? Fill in both languages.** An empty language shows empty texts to players using that language setting.
- **The image is required** — keep campaign visuals consistent in style (same ratio, same feel).
- **Deleted is not gone.** You can bring deleted campaigns back with **Restore**.

---

## ✅ Checklist before publishing

- [ ] Name + description in every language your organisation uses
- [ ] Image (and icon) uploaded
- [ ] Access set correctly (and tags checked)
- [ ] At least one challenge with at least one module, played through yourself
- [ ] Points/stars/leaderboard settings as intended
- [ ] Certificate on or off — a deliberate choice
- [ ] Dashboard tile arranged (automatically or via TK-21)

---

## 🔍 Done? How to check

Open the player environment (menu → **View app** or the dashboard) and check: is the campaign there, are the image and text right, and can you start it? If you use access via tags, also test with an account **without** that tag — that account should **not** see the campaign.
