# 🎬 Task card TK-26 — Create & manage a gamified video (HiHaHo)

> **For game managers.** How to build an interactive video in HiHaHo, put it in the right folder and get it into LearnStrike as a module.
> **Status:** v1.0 · 30-09-2026 · part of the LearnStrike Knowledge Base · language: EN.

---

**Two systems, one chain.** You build the video and all its interaction (questions, buttons, chapters) in HiHaHo Studio. LearnStrike then picks the video up and you place it as a module in a challenge. Adding that module is covered in TK-25; this card covers everything before it.

---

## 📌 Highlights

| | |
|---|---|
| **Where** | HiHaHo Studio (studio.hihaho.com) → **My folders** → [your organisation's folder]; then Control Panel → module **Gamified video** (TK-25) |
| **When to use** | Explanation with check questions, instruction or process video, a case with choices, introducing a learning goal |
| **What you need** | A HiHaHo account with access to your organisation's folder, and a video (upload, YouTube or Vimeo) |
| **Folders** | Every organisation has its own folder in HiHaHo. Only videos in a folder linked to your organisation show up in LearnStrike |
| **Synchronisation** | LearnStrike fetches new videos automatically. It isn't instant: allow a few hours [still to verify] |
| **Permissions** | In HiHaHo: User or Administrator role on the folder. In the Control Panel: Manager role (or higher) for the module |

---

## 🚀 Step by step

**Getting ready (once)**

1. Accept the HiHaHo invitation you receive by email and finish setting up your account. The invitation is only valid for a limited time; if it has expired, ask 4Growth for a new one.
2. Check with 4Growth that your organisation's HiHaHo folder is linked to your LearnStrike environment. 4Growth does this.

**Building the video in HiHaHo**

3. Open **My folders**, choose your organisation's folder and click **+ New interactive video**. Always create the video in the right folder straight away; if it ends up elsewhere, move it first.
4. Choose the source: upload a file or link a YouTube or Vimeo video. Keep it short, 1 to 3 minutes per topic.
5. Add the interaction: questions, buttons, a table of contents or a pause screen. The HiHaHo tutorials at the bottom of this card show you how.
6. Set up the **end score screen** in the video settings. HiHaHo decides whether the module in LearnStrike is passed, based on the answers given in the video.
7. Put a short instruction on the end screen telling the player to click **Next**. Without that click the score doesn't always reach LearnStrike [still to verify].

**Publishing**

8. Under **Share**, choose any publication setting other than **Only me**. A video set to "Only me" counts as unpublished and won't come through to LearnStrike [still to verify].
9. Working from a copy ([Duplicaat] in the name)? Give it a clear name first. Players and colleagues see that name in LearnStrike.

**Into LearnStrike**

10. Wait for the synchronisation, then open the **Gamified video** module in the Control Panel (see TK-25). If the video still isn't there, an administrator can click **Import Gamified videos** under **Gamified videos** in the Control Panel to start the import right away.

## ⭐ Golden rules & common mistakes

- **Video not showing up in LearnStrike?** Run through this list: is it in the right folder, is it published (not "Only me"), is the folder linked to the organisation, and has the synchronisation run yet?
- **Folder names can differ.** LearnStrike sometimes shows an older folder name than HiHaHo does. When in doubt, go by the folder number (external ID).
- **Test as a player.** Play the video to the end in the player environment and check that the points and completion show up.
- **Two languages?** Put all on-screen text in HiHaHo's interaction layer, not in the video itself. Then a copy with translated texts gives you a second language version quickly. HiHaHo can also generate subtitles.
- **Reuse the structure.** Copy interactions or work from a template when several videos share the same set-up. It saves a lot of clicking.

## 🔍 Done? How to check

Open the challenge in the player environment (menu → **View app**) and play the video to the end. Do the interaction moments work, do you see your points, and is the module marked as completed afterwards? If not: run through the first golden rule and let 4Growth know.
