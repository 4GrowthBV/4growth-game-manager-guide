# Rollen & rechten

## De rollen

| Rol | Wat mag deze rol |
|---|---|
| Administrator | Platformbeheer door 4Growth |
| Reseller | Als manager + organisaties (klanten) aanmaken en beheren |
| Manager | **De game manager**: gebruikers + content + insights van de eigen organisatie |
| Gebruiker | Speelt; alleen de spelersomgeving |
| Gast-gebruiker | Speelt anoniem; geen leaderboard, voortgang niet bewaard |

Rollen gelden **per organisatie** (een persoon kan in organisatie A manager zijn en in B speler).

## Capabilities-matrix

| Capability | User | Manager | Reseller | Admin |
|---|---|---|---|---|
| Spelen, leaderboard | ✓ | ✓ | ✓ | ✓ |
| Control Panel (2FA verplicht) | – | ✓ | ✓ | ✓ |
| Gebruikers & content eigen organisatie | – | ✓ | ✓ | ✓ |
| Insights & exports | – | ✓ | ✓ | ✓ |
| Organisatie-instellingen (thema, talen, gameplay, profiel, onboarding) | – | ✓ | ✓ | ✓ |
| Organisaties aanmaken (klanten) | – | – | ✓ | ✓ |
| Platformbeheer (alleen 4Growth) | – | – | – | ✓ |

## Praktisch

- Nieuwe game manager? Uitnodigen met rol **Manager** (TK-03) of bij bestaande gebruiker de rol aanpassen (TK-01).
- Manager-toegang vereist **2FA**. Komt een gebruiker niet meer binnen, zie TK-01.
- Of je organisaties kunt aanmaken (reseller), stelt 4Growth in.
